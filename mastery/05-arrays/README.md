# Section 5 — Arrays Extra Practice

Optional practice for building accuracy and fluency with common array operations.

## Practice levels

- **Level 1 — Fundamentals:** one behavior at a time with explicit constraints.
- **Level 2 — Applied practice:** larger object collections and multiple conditions.
- **Level 3 — Method selection:** the prompt describes the required result without naming the operation to use.

Start with Level 1. Preserve your first attempt before correcting failures.

### Run Level 1

```bash
node mastery/05-arrays/tests/run-tests.js
```

### Run Level 2

```bash
node mastery/05-arrays/tests/run-applied-tests.js
```

### Run Level 3

```bash
node mastery/05-arrays/tests/run-selection-tests.js
```

See `resources.md` for documentation and an explainer video. When using these exercises as a cold check, attempt the assigned level before reviewing resources.
