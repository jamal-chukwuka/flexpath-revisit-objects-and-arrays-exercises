## What to be able to distinguish

- one matching element vs. every matching element;
- transforming every element vs. selecting some elements;
- producing a new collection vs. performing a side effect;
- mutating an existing array vs. returning a different outer array;
- shallow copying the outer array vs. copying nested objects;
- choosing an operation from the required behavior instead of from a method name in the prompt.
